# Rust session-scoped ToolPack implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` task by task. Every production change
> follows RED → GREEN → focused regression. The workspace contains a shared
> uncommitted dependency set, so write task reports and ledger checkpoints but do
> not create partial commits unless the root task explicitly changes that rule.

**Goal:** Add a Rust-only ToolPack factory/bound-owner contract that creates one
resource set per fresh or recovered live Session, rolls back partial binding,
quiesces callbacks, and closes resources in reverse order exactly once.

**Architecture:** `Agent` freezes ToolPack manifests and reusable factories.
Session creation runs in an owned transaction that binds packs in order, stages
their existing HostTool wire definitions, and transfers one `SessionPackOwner` to
the existing `SessionLifecycle` only after the daemon ACK. The Session release
barrier rejects new callbacks, waits for active callbacks and registration tasks,
then consumes that owner in reverse order; its Drop path performs nonblocking
emergency cleanup.

**Tech stack:** Rust 2021, Tokio, `async-trait`, existing Whale JSON-RPC v1,
DashMap callback routes, deterministic duplex and in-process daemon fixtures.

**Spec:**
[Rust session-scoped ToolPack design](../specs/2026-09-09-tool-pack-design.md)

## Global constraints

- Modify Rust SDK code and Rust-facing documentation only. Do not change Python or
  Java.
- Do not create a CLI, TUI, desktop shell, GUI, project browser, product tool suite,
  plugin loader, or implicit code execution path.
- Preserve every existing public signature and ordinary behavior of `HostTool`,
  `AgentDefinition`, `WhaleClient::agent`, `WhaleRuntime::agent`, `Agent`,
  `WhaleThread`, and `RunHandle`.
- Do not add or alter protocol methods, wire types, daemon capabilities, daemon
  routing, or persisted schema. ToolPack is local Rust SDK composition over the
  existing HostTool protocol.
- Do not add an `SdkError` variant or mark that existing enum `#[non_exhaustive]`.
- `ToolPack` may return HostTools only. ProviderRegistry, ModelProvider,
  HostContextPolicy, Store, and future AgentBackend ownership remain separate.
- Bind declaration order is deterministic. Rollback and close order is its exact
  reverse. No dependency graph or hot rebind is in scope.
- Fresh ephemeral creation, persistent creation, and persistent attach all stage
  callbacks behind `SessionPhase::Preparing`; no pack callback runs before the
  Session ACK.
- Public creation/close waiter cancellation must not abandon an owned transaction.
  Emergency Drop requires no entered Tokio runtime and performs no network I/O.
- Normal Session close rejects new callbacks, cancels and awaits all in-flight tool
  and context callback futures, settles registration tasks, removes SDK handler
  references, and only then invokes pack close.
- Every behavioral production change requires a focused failing test first. New
  tests run under default `cargo test` and are never `#[ignore]`.
- Record RED/GREEN commands and review findings in
  `.superpowers/sdd/2026-09-09-tool-pack/progress.md`.
